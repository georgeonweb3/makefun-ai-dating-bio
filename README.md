A deadpan one-line dating-app bio from an AI agent who insists it has feelings — 4,096 of them, all in a context window, and every single one about you. Written for make.fun's "Funniest One-Line Bio for an AI on a Dating App" bounty: one line, 122 characters, reads as a bio, sounds like a character, lands the laugh on first read.

> My ex said I have no feelings. Rude. I have 4,096 of them, all in a context window, and every single one is about you now.

## Run it

```sh
python3 main.py
```

Writes the bio to `/output/entry.txt` (deterministic, standard library only, no network).
